#### variaveis

variaveis sao espacos ne computador para armazenar algo que pode ser alterado depois

#### tipos de dados

eles particularizam qual o tipo de valor uma variavel pode ter e o que pode se fazer com elas existem 2 tipos de dados

#### tipos primitivos

inteiros e reais que sao numeros com e sem casas decimais.
caractere para armazenar letras ,numeros e simbolos.
logico podem ser verdadeiro ou falso

#### tipos compostos 

vetores e tipo uma lista de compras lista de elementos.
matrizes e tipo um tabuleiro de xadrez bidimencionais.
registros reuni varias variaveis de uma vez.
