#### FORMAS DE COLABORAÇÃO
Trabalho Direto em Repositórios da Organização: Membros da equipe recebem permissões diretas no mesmo repositório,
criando branches individuais e fazendo push sem precisar duplicar o projeto

Modelo de Fork e Pull Request: Usado principalmente em projetos de código aberto (open source) com pessoas externas. 
O colaborador copia o repositório para sua própria conta, 
faz as alterações e propõe a integração de volta ao projeto original via Pull Request

Gestão de Tarefas com Issues e Projects: O uso de GitHub Issues e quadros Kanban ajuda a rastrear bugs,
planejar sprints e associar discussões diretamente ao código

#### FORMAS DE BOAS PRÁTICAS 
Nomenclatura de Branches: Use padrões descritivos e organizados,
como feature/nome-da-tarefa ou fix/descricao-do-bug

Commits Atômicos e Claros: Faça commits frequentes focados em uma única alteração.
Escreva mensagens curtas e objetivas no modo imperativo

Pull Requests Pequenos: Divida grandes entregas em partes menores para agilizar a revisão de código  e facilitar a identificação de erros

Proteção de Branches: Configure regras de proteção na branch main no painel de Configurações do Repositório para exigir revisões de colegas
e testes automatizados antes de permitir o merge
