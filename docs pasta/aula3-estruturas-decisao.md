#### O QUE É
Estruturas de decisão são comandos que permitem ao programa desviar o caminho do código com base em testes lógicos (verdadeiro ou falso). 

#### EXEMPLOS
As principais ferramentas são o SE/SENÃO para condições gerais 
e o ESCOLHA/CASO para múltiplos valores fixos, permitindo escolhas dinâmicas como em estruturas de decisão na DIO
